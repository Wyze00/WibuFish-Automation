# OVERVIEW

Skrip otomatisasi mancing di WibuFish
- Ikan rarity epic ke bawah bisa otomatis
- Ikan rarity legend ke atas semi-otomatis (sampe strike otomatis, mancingnya manual)

# INSTALLATION

Clone this repository

```sh
git clone https://github.com/Wyze00/WibuFish-Automation
```

Install all dependencies

```sh
npm install
```

# START PROJECT

Normal mode

```sh
npm run start
```

Debug mode

```sh
npm run start:debug
```
